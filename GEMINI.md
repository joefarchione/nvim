## Worktree Rules

The main worktree (`cave-research`) is **READ-ONLY**. It stays on `staging` and must NEVER have files edited, created, or modified. `staging` and `main` are both read-only branches -- changes only arrive via PR merges from feature branches. All file changes happen in feature worktrees only.

**CRITICAL: The FIRST two actions for any implementation task are `git pull` then `git worktree add`. No file edits before the worktree exists.** Do not read-then-edit in `cave-research` and move changes later. Create the worktree first, then read and edit exclusively in it.

```bash
# Step 1: Pull latest staging in the main worktree
git pull

# Step 2: Create a new feature worktree (always branch from origin/staging)
git worktree add ../cave-<name> -b feature/<name> origin/staging

# After PR merges, clean up
git worktree remove ../cave-<name>
```

- Worktrees live at `../cave-<name>` (sibling to `cave-research` in the workspace directory)
- For follow-up work on an existing PR, use `/follow-up <PR#>` instead of branching from staging.

## Pipeline

The `@pipeline` agent (`.claude/agents/pipeline.md`) orchestrates the eight-phase agentic simulation loop:

```
Phase 1: Domain       [surveyor + archaeologist + ontologist]
Phase 2: Analysis     [human]
Phase 3: Specification [human or agent]
Phase 4: Input        [input]
Phase 5: Model        [modeler]
Phase 6: Strategy     [strategist]
Phase 7: Validation   [analyst]
Phase 8: Output       [output]
```

### Agent Discovery

**Template = single source of truth.** Base agent content lives in `src/Templates.MyDomain/agents/`. The sync script generates self-contained domain agents by merging base patterns with domain-specific content.

**Structure:**
- `src/Templates.MyDomain/agents/<role>.md` -- Base templates with `{{DomainName}}` placeholders and `<!-- DOMAIN: ... -->` extension points
- `<domain>/agents/<role>.md` -- Self-contained domain agents (generated by sync, domain content in `<!-- BEGIN/END DOMAIN CONTENT -->` markers)
- `.claude/agents/<group>-<project>-<role>.md` -- Redirects to domain agent files
- `src/Cave/agents/<role>.md` -- Engine-specific agents only (calibrator, compiler, composer, strategist, etc.)

**Sync script:**
```bash
./scripts/Sync-DomainAgents.ps1              # Sync all domains
./scripts/Sync-DomainAgents.ps1 -Domain "Actuarial"        # Sync one domain
./scripts/Sync-DomainAgents.ps1 -New -Domain "Climate" -Group "climate"  # Scaffold new domain
```

**11 template roles:** analyst, archaeologist, guide, input, modeler, ontologist, output, pipeline, researcher, surveyor, translator.

**12 engine-specific roles** (in `src/Cave/agents/`, no template equivalent): calibrator, compiler, composer, consolidator, consultant, coordinator, dispatcher, dsl-designer, exporter, reconciler, reviewer, strategist.

Aliases: `organizer` -> `ontologist`, `optimizer` -> `strategist`, `quant`/`critic` -> `analyst`.
